# Security Policy

## Supported versions

Only `main` and the latest published image (`ghcr.io/derpsen/magguuui-website:latest`) receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Preferred: GitHub Private Vulnerability Reporting. Use "Report a vulnerability" under the repository's Security tab (Security Advisories).
- Alternative: email contact@magguu.xyz.

Include the affected URL or component, the steps to reproduce, and the impact. Reports are acknowledged as soon as possible, and a fix is released on `main` and in the next image.

Out of scope: findings that need a compromised admin account or physical access, and automated scanner output without a working proof of concept.
